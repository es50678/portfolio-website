## Installation

1. Install the dependencies:
  ```bash
  npm install
  ```

## Development

To start the development server, run:
```bash
npm start
```

## Deployment

To deploy the website to GitHub Pages, follow these steps:

1. Build the project:
  ```bash
  npm run build
  ```

2. Deploy to GitHub Pages:
  - commit changes to branch `gh-pages`
